## 7. Evidence retention

- source／test result: Git commit、PR、required check、CodeQL
- image／SBOM／VEX／risk: CI／Release artifactとattestation
- deploy: Production Release summary、Change Set、CloudFormation event
- live behavior: content-free timestamp、terminal state、operator observation。opaque Debate IDが必要な
  場合はprivate operator evidenceへ限定し、public docs／PRへ複製しない。
- incidents: minimal direct-cause log、cleanup、lock／Change Set／stack safe state

question、output、persona、token、private identifierを証拠へ複製しない。
