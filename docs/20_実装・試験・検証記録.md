## 4. Important resolved incidents

| Incident | Root cause | Enduring control |
|---|---|---|
| 初回Runtime rollback | `DescribeTaskDefinition`をresource scopeした | 対象Actionだけ`Resource: "*"`、application exact validation |
| release image不一致 | pytest bytecodeがpath contextへ混入した | bytecode禁止、fresh SHA checkout、actual context test |
| referrer検証失敗 | 同digestの過去attestationも数えた | attestation前後のACTIVE referrer差分だけを検証 |
| Discord初回応答失敗 | cold invocationが3秒期限を超えた | HTTP ingress／SnapStart／短いinitial response |
| Statusの取り違え | debateではなく共有状態へ遅延更新した | Debate／Attempt単位のfenceと収束 |
| terminal delivery停滞 | process lossとDiscord POST結果が曖昧だった | GenerationCheckpoint、Outbox v2、history reconciliation |
| farewell欠落 | shutdown直前処理と厳密なsource照合 | 停止5分前、citation 1件、限定retry、best-effort |
| static digest loop | cross-run完全一致をrequired化した | run内evidenceを検証し、静的baselineを廃止 |

## 7. Evidence retention

- source／test result: Git commit、PR、required check、CodeQL
- image／SBOM／VEX／risk: CI／Release artifactとattestation
- deploy: Production Release summary、Change Set、CloudFormation event
- live behavior: content-free timestamp、terminal state、operator observation。opaque Debate IDが必要な
  場合はprivate operator evidenceへ限定し、public docs／PRへ複製しない。
- incidents: minimal direct-cause log、cleanup、lock／Change Set／stack safe state

question、output、persona、token、private identifierを証拠へ複製しない。
