## Project overview

Discord上で3つのprivate-configured personaが初回意見、相互参照後の最終案、匿名投票を行い、moderatorが進行、集計、最終決定、記録を担当する単一Guild向けBotを構築する。

詳細設計と主要sliceの実装は完了し、Stateful、Runtime、Operations、CostGovernanceの4 StackをProduction Releaseで運用している。現在のscale-to-zero構成は、署名済みDiscord HTTP Interaction受付、3つの責務分離Lambda、DynamoDB永続FIFO、ARM64 On-Demand Fargateの`desiredCount=0`→1収束、1分Reconcilerで構成する。DynamoDBはschema v7、control-record manifest v2である。待機FIFO 20件と実行中のglobal 3 slotは別の上限とし、3分は非terminal起動警告、15分はterminal failure、30分は最後の討論がOutbox／Statusを含め完全終了した後の停止待機時間とする。旧Fargate Spot専用・`desiredCount=1`常時稼働設計は廃止済みである。

code、DynamoDB Local、mock／Stubber、CDK test、cdk-nag、synth、canonical CIに加え、Production Releaseと段階live acceptanceで検証している。Discord Interactions Endpoint、4 Bot、`/shittim`、deployment guard、scale-to-zeroはproductionへ反映済みである。本番はLuna standardだけを使用し昇格しない。Responses API Multi-agent betaは使用せず、Pythonがオーケストレーションする。

## Source of truth・GitHub mirror

本folder直下の17文書と補助正本directory配下の3文書、合計20文書を公開可能な正本とする。GitHub repositoryの`docs/`はreview・履歴・CI検証用の一方向mirrorであり、直接編集しない。同期sourceは`--source`または`SHITTIM_DOCS_SOURCE`で明示する。

補助正本directory `100_Ondemand Fargate/`の`10_scale-to-zero-goal.md`、`30_scale-to-zero-commit-plan.md`、`20_scale-to-zero-completion-checklist.md`はscale-to-zeroの要件/設計、commit/中断復旧、完了判定をそれぞれ定義する。sync toolはこの正確なdirectory名と3ファイルを検証し、同じ相対pathで公開`docs/`へmirrorする。local絶対pathは公開文書に記録しない。本番固有値とpersona内容も非公開operator sourceとversion付きSSM parameterへ分離する。
