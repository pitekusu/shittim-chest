# シッテムの箱 ドキュメント索引

## 1. 1.0 snapshot

**The Shittim Chest**（シッテムの箱）は、private Discord Guildで3人のAI参加者が
討論し、Pythonが投票結果から勝者を決めるBotである。

| 領域 | 1.0の状態 |
|---|---|
| 受付 | 署名付きHTTP Interaction、耐久FIFO、公開Status、再試行／中止 |
| 討論 | 共通Evidence、初回意見、最終案、匿名投票、Python winner、勝者発表 |
| AI | Luna standard、Structured Outputs、共有agentic Web search、private persona名簿 |
| 永続化 | DynamoDB schema v7、fencing、generation checkpoint、ordered Outbox v2 |
| 実行環境 | ARM64 On-Demand Fargate、通常0 task、最大1 task、30分idle停止 |
| 運用 | 5 CDK stack、監視、予算、drift、署名付きProduction Release |

本書のstatusは製品文書のbaselineを示す。exact commit、PR、workflow run、artifactは
GitHubを正とし、[[20_実装・試験・検証記録]]には現在の要約だけを残す。

## 3. Authority

- public-safeなObsidian notesを正本とし、GitHub `docs/`はbyte mirrorとする。
- 要求変更は01、設計判断は02、interfaceは10〜17、合否は18へ一度だけ記録する。
- 実装が最終的な挙動を表すが、文書との差異を発見した場合は無断でどちらかへ寄せない。
- production secret、identifier、persona本文、利用者の質問を正本やmirrorへ保存しない。
- package／toolのexact versionは`uv.lock`、root `package-lock.json`、
  `.github/tool-versions.json`を正とし、文書へ重複固定しない。
