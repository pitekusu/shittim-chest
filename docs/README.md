# シッテムの箱の設計文書

GitHubのこのリポジトリにある `docs/` が公開仕様・設計・運用手順の正本です。[ドキュメント索引](00_シッテムの箱_ドキュメント索引.md)から、機能ごとの設計や実装・検証の記録を参照できます。

## 変更する手順

1. 索引の「変更内容と編集先」から担当文書を選ぶ。実装によって仕様や運用が変わる場合は、同じ変更で担当文書を更新する。
2. リポジトリのルートで検査し、GitHubのプルリクエストで差分を確認する。

```sh
uv run --frozen python -m tools.check_docs
uv run --frozen python tools/check_public_surface.py
git diff --check
```

## 書き方

- 文書間は相対Markdownリンクを使い、パスの空白は `%20` にする。構成・手順・状態遷移の図にはGitHubで表示できるMermaidを使う。
- 仕様は担当文書に記載し、他の文書からはリンクで参照する。試験結果や配信状態には確認できた事実を書く。
- 認証情報、非公開の識別子、利用者の質問・回答、人格プロンプト本文、端末固有のパスは公開文書に含めない。
- 文書を追加する場合は索引と、`tools/sync_docs.py` の文書検査対象一覧も更新する。

設計の提案方法と文書の利用条件は [文書ライセンス](LICENSE.md) を参照してください。
